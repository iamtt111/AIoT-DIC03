# Spec Delta

## Purpose

依官方環境資料、明確偏好與可版本化規則，產生可重現的分站及全行程出門建議。

## ADDED Requirements

### Requirement: 產生可追溯的分站建議
系統 SHALL 以可用的環境快照、行程活動與明確偏好，透過版本化規則判斷降雨準備、紫外線防護、空品防護及冷熱舒適。每個判斷 MUST 記錄警示類別、優先級、建議行動、使用的 `ruleId`、輸入證據、偏好版本或因素及資料限制。重要健康防護提醒 MUST 不受舒適偏好移除。

#### Scenario: 高紫外線的長時間戶外活動
- **WHEN** 有效 UV 資料與戶外暴露程度符合防護規則
- **THEN** 系統為該站建立帶有規則識別與資料證據的紫外線防護提醒

#### Scenario: 偏好降低舒適提醒優先度
- **WHEN** 使用者的舒適偏好降低某項舒適提醒的重要性且同站存在健康防護提醒
- **THEN** 系統可調整舒適提醒的呈現優先度但保留健康防護提醒

### Requirement: 處理受資料品質影響的建議
系統 MUST 對資料缺漏、過期、時段不符或空間粒度不足的面向限制或停止對應判斷，並將限制納入結果。系統 MUST NOT 對缺少適用資料的面向產生確定性風險結論。

#### Scenario: 缺少適用空品資料
- **WHEN** 行程站的空品面向被標示為 `missing` 或 `unavailable`
- **THEN** 系統不產生空品風險判定並在結果中說明空品資料限制

### Requirement: 彙整全行程建議
系統 SHALL 將所有分站建議彙整為全行程摘要，依重要防護優先於舒適提醒的原則排序，並保留每個提醒適用的站點、時段、證據及限制。系統 MAY 合併重複提醒，但 MUST NOT 移除其分站依據。

#### Scenario: 跨站不同提醒
- **WHEN** 不同站點分別觸發降雨與空品防護提醒
- **THEN** 全行程摘要列出兩項提醒及其各自對應的站點與時段
