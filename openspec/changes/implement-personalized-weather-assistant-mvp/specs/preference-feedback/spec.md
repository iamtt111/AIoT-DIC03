# Spec Delta

## Purpose

使使用者能掌控明確偏好及行後回饋，並確保系統不會未經確認改寫長期個人設定。

## ADDED Requirements

### Requirement: 管理明確偏好及其版本
系統 SHALL 允許使用者檢視、建立、修改與刪除雨具接受度、防曬優先度、空品提醒敏感度及冷熱偏好等明確偏好。系統 MUST 為已確認的偏好版本建立識別，且每次建議 MUST 關聯使用的偏好版本。

#### Scenario: 使用者更新偏好
- **WHEN** 使用者確認新的防曬優先度
- **THEN** 系統建立新的已確認偏好版本並供後續建議使用

#### Scenario: 使用者刪除偏好
- **WHEN** 使用者刪除某項明確偏好
- **THEN** 系統不再將該偏好套用於後續建議

### Requirement: 以確認流程處理行後回饋
系統 SHALL 允許使用者提交天氣與空品符合度、建議有用性及選填文字回饋。系統可由多筆回饋建立具理由與證據摘要的偏好更新候選，但 MUST 將候選標示為待確認，且 MUST NOT 在使用者接受前改寫長期偏好或降低健康防護提醒。

#### Scenario: 產生待確認偏好候選
- **WHEN** 系統根據回饋辨識出可能的舒適偏好調整
- **THEN** 系統建立含理由與證據摘要的待確認候選而不修改目前偏好

#### Scenario: 使用者拒絕候選
- **WHEN** 使用者拒絕待確認的偏好更新候選
- **THEN** 系統將候選標記為已拒絕且維持既有偏好版本
