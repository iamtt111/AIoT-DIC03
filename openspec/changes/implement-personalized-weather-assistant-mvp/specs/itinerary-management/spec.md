# Spec Delta

## Purpose

讓使用者能建立可供環境資料查詢與個人化建議使用的臺灣多站行程。

## ADDED Requirements

### Requirement: 建立多站行程
系統 SHALL 允許使用者在同一份行程中建立一個以上的停留站。每一站 MUST 包含地點、開始與結束時間、活動型態及戶外暴露程度；系統 MUST 保留各站的獨立識別與時間範圍。

#### Scenario: 建立兩站行程
- **WHEN** 使用者提交含有上午上課站與下午戶外活動站的有效行程
- **THEN** 系統儲存兩個可獨立分析的行程站

#### Scenario: 缺少必要欄位
- **WHEN** 使用者提交缺少停留時間或戶外暴露程度的行程站
- **THEN** 系統指出缺少的欄位且不對該站產生建議

### Requirement: 標準化行程站的地點與時段
系統 SHALL 將有效的臺灣行程地點標準化為可用於資料查詢的座標、鄉鎮市區及空品區，並驗證開始時間早於結束時間。當地點或時間有歧義、無法解析或不在支援範圍內時，系統 MUST 要求使用者修正或確認，不得以猜測值繼續處理。

#### Scenario: 可解析的臺灣地點
- **WHEN** 使用者輸入可辨識的臺灣地點與有效時間區間
- **THEN** 系統產生含座標、鄉鎮市區、空品區及時間範圍的標準化行程站

#### Scenario: 模糊地點
- **WHEN** 使用者輸入對應多個地點或無法辨識的地點名稱
- **THEN** 系統要求使用者選擇或修正地點且不執行資料查詢
