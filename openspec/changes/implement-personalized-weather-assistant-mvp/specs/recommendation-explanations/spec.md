# Spec Delta

## Purpose

讓使用者能檢視每項建議的資料依據與限制，並安全地取得不改變決策的自然語言說明。

## ADDED Requirements

### Requirement: 呈現建議證據與限制
系統 SHALL 對每項分站與全行程建議呈現適用地點、時段、建議行動、資料來源、資料類型、更新或發布時間、規則依據與資料限制。當資料品質限制影響判斷時，系統 MUST 將該限制與受影響的面向一併呈現。

#### Scenario: 顯示可追溯建議
- **WHEN** 使用者檢視已產生的分站建議
- **THEN** 系統提供該建議的來源資料、適用時段、規則識別與限制資訊

### Requirement: 限制 LLM 解釋的決策權限
系統 SHALL 僅允許 LLM 將既有結構化行程、建議、證據與限制轉換為摘要或回覆「為什麼」問題。LLM MUST NOT 新增未記錄的天氣或空品數值、來源、規則判定、警示優先級或健康防護結論；不一致或失敗的生成結果 MUST 被拒絕，並改呈現結構化資料。

#### Scenario: 詢問建議原因
- **WHEN** 使用者詢問某項已產生建議的原因
- **THEN** 系統僅根據該建議已保存的證據與限制產生說明

#### Scenario: 生成內容與記錄不一致
- **WHEN** LLM 輸出包含未記錄的數值、來源或與結構化判斷衝突的結論
- **THEN** 系統不採用該輸出並保留原始結構化建議、證據與限制
