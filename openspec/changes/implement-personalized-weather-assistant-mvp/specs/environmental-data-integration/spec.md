# Spec Delta

## Purpose

為每個已標準化行程站取得可追溯的官方天氣與空氣品質資料，並公開其適用限制。

## ADDED Requirements

### Requirement: 取得並保留官方環境資料脈絡
系統 SHALL 依行程站的地點與時段取得適用的 CWA 天氣資料，以及 MOENV 即時空品資料或官方隔日空品預報。每筆使用的資料 MUST 記錄來源名稱、資料類型、發布時間、取得時間、有效時段與空間參照；即時觀測與預報 MUST 被標示為不同資料類型。

#### Scenario: 未來行程使用天氣預報與空品預報
- **WHEN** 行程站位於 CWA 預報與 MOENV 隔日空品預報的適用範圍
- **THEN** 系統保存對應的預報資料及其發布、有效、空品區與時段資訊

#### Scenario: 進行中的行程使用即時空品
- **WHEN** 行程站正在進行且存在可用的 MOENV 測站資料
- **THEN** 系統使用最近可用測站的即時資料並記錄測站、距離與發布時間

### Requirement: 檢查資料的時空適用性與品質
系統 SHALL 對每個資料面向檢查必要欄位、發布與有效時間、空間粒度及來源可用性，並在適用時標示 `missing`、`stale`、`spatially-coarse` 或 `unavailable`。系統 MUST 將品質結果傳遞給建議與結果呈現；不得以目前觀測值替代未來預報，或推算未提供的資料。

#### Scenario: 空品預報不適用
- **WHEN** 未來行程站超出官方空品預報的適用範圍
- **THEN** 系統將該空品面向標示為 `unavailable`，保留可用天氣資料，且不以其他資料推定空品風險

#### Scenario: 資料空間粒度不足
- **WHEN** 資料只能代表較大區域而無法支持精確地點結論
- **THEN** 系統標示 `spatially-coarse` 並保存該資料的空間參照
